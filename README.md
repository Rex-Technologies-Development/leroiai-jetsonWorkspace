# Leroi AI — Jetson ROS 2 Workspace

ROS 2 (`colcon`) workspace for running the Leroi AI stack on NVIDIA Jetson.

This repo is structured as a standard ROS 2 workspace:

- `src/` — source packages
- `build/`, `install/`, `log/` — generated by `colcon` (safe to delete/rebuild)

Main build command:

```bash
colcon build --symlink-install
```

## Project structure

Each ROS 2 package usually contains:

- one or more node files or node entrypoints
- any supporting Python/C++ code the node needs
- `package.xml` and build/setup metadata

Launch files live in the bringup package, which is used to start one or more nodes together.

## Packages

### `leroi_bringup` (ament_python)

Launch files for starting the stack.

- Launch files: `perception.launch.py`, `robot.launch.py`
- Example:
	- `ros2 launch leroi_bringup perception.launch.py`

### `leroi_perception` (ament_python)

Perception node. Today it publishes a heartbeat and (optionally) **fake** detections as JSON for end-to-end plumbing.

- Node: `perception_node` (`ros2 run leroi_perception perception_node`)
- Topics:
	- `/perception/status` (`std_msgs/String`) — "perception_node alive"
	- `/perception/detections` (`std_msgs/String`) — JSON string payload
- Parameters:
	- `publish_rate_hz` (double, default `2.0`)
	- `enable_fake_detections` (bool, default `true`)

### `leroi_decision` (ament_python)

Decision-making node scaffold.

- Node entrypoint: `decision_node` (currently prints a hello message)
- Supporting code: `leroi_decision/decision_node.py`

### `leroi_policy` (ament_python)

Policy node scaffold.

- Node entrypoint: `policy_node` (currently prints a hello message)
- Supporting code: `leroi_policy/policy_node.py`

### `leroi_serial_messenger` (ament_python)

Serial comms node scaffold (intended for Jetson ↔ microcontroller messaging).

- Node entrypoint: `serial_messenger_node` (currently prints a hello message)
- Supporting code: `leroi_serial_messenger/serial_messenger_node.py`

### `leroi_telemetry` (ament_python)

Telemetry node scaffold.

- Node entrypoint: `telemetry_node` (currently prints a hello message)
- Supporting code: `leroi_telemetry/telemetry_node.py`

### `leroi_interfaces` (ament_cmake)

Interface package scaffold (intended home for custom `msg/`/`srv/` definitions).

Note: At the moment this package contains only the CMake/package scaffolding (no message/service definitions yet).

## Prerequisites

- ROS 2 Humble (this workspace has been built against `/opt/ros/humble`)
- `colcon` + standard ROS 2 build tools

On a machine with ROS 2 installed, you should have access to `colcon` and `ros2` on your PATH after sourcing the ROS setup script.

## Build

From the repo root:

```bash
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
```

To clean and rebuild:

```bash
rm -rf build/ install/ log/
colcon build --symlink-install
```

## Run

### Launch perception (recommended)

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch leroi_bringup perception.launch.py
```

### Run the node directly

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 run leroi_perception perception_node
```

Override parameters:

```bash
ros2 run leroi_perception perception_node --ros-args \
	-p publish_rate_hz:=5.0 \
	-p enable_fake_detections:=true
```

### Inspect topics

```bash
ros2 topic list | grep perception
ros2 topic echo /perception/status
ros2 topic echo /perception/detections
```
